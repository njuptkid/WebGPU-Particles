# 消散编织纹修复

默认渲染路径已修复释放阈值细粒度 hash 的规则斜纹。仅将 birth 中的 `hash(floor(p*.65))` 改为 `grainHash(floor(p*.65))`，保留频率 .65、幅度 .20、低频 noise、流场、粒径、寿命和颜色。

```glsl
float grainHash(vec2 p) {
 vec3 v=fract(vec3(p.xyx)*.1031);
 v+=dot(v,v.yzx+33.33);
 return fract((v.x+v.y)*v.z);
}
```

同步更新 common、原图片元、内外场景粒子顶点，以及两种 GPU 噪声烘焙 shader，避免原图与粒子使用不同释放阈值。生成的近似/组合实验也继承修复。固定源坐标提供稳定随机结果，不按帧换种子。

## 查看效果

启动 `node tools/serve.cjs`，打开 `/demo/compare.html`。默认模式为“消散编织纹修复（前后对照）”，角度 150°：

- 左侧“修复前”：保留旧细粒度 hash。
- 右侧“修复后”：使用新的 grainHash，不启用其他近似或预计算。
- 可切换“仅原始内容消散”，重点观察蓝色卡片上的斜向规则纹理；也可同步播放完整开合。
- 切换其他算法实验时，两侧均使用已修复的释放规则，以免混合比较两个改动。

正式双屏演示 `/demo/index.html` 默认使用修复后算法。无需开启预计算开关。

## 验证与限制

`node tools/run-browser-tests.cjs --release-fix` 检查应用/桌面、内/外屏、双方向、0/30/70/110/150/170/180°、原始/缓存路径一致性、端点、复现性和 GPU 错误。161 项通过，报告与截图：

- `tests/release-fix-report.json`
- `tests/release-fix-preview.png`
- `tests/release-fix-base-preview.png`

画面中的规则斜纹明显减弱，正常的随机碎化颗粒仍保留。这是视觉修复，不宣称 GPU 加速；其他设备和缩放比例仍需评审。

API 的 `legacyRelease: true` 仅用于无预计算、无近似的历史对照，默认 false；禁止将旧 birth 与新预计算或近似组合，避免掩码与粒子失配。该历史路径不用于算法 GPU 基准。

构建修改后运行 `node tools/build-shaders.cjs`。后续若调整 grainHash，应保持所有 birth 和烘焙路径一致。
