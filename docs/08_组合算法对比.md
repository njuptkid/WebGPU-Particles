# 组合算法对比

打开 `/demo/compare.html`，右侧选择“组合优化实验（7 项）”。左侧为原算法，两侧使用相同素材、源点、粒子数量、角度、方向和流场时间。

## 组合内容

| 项目 | 组合后的实现 |
| --- | --- |
| 公共流场参数 | 每帧在 CPU 求公共相位、幅度和半径，经 uniform 传入 |
| 动态域扭曲 | 去掉嵌套 warp，保留两个尺度的动态值噪声 |
| 动态 hash | 两次动态 noise 都使用无 sin 的浮点 hash |
| 涡区包络 | exp(-z) 改为 max(0,1-z/4)^4 |
| 粒子圆点 | 使用距离平方塑形，改变柔边覆盖分布 |
| 空间波形 | 四个空间正弦改为平滑三角波近似 |
| 饱和增长 | 1-exp(-x) 改为有理式 |

未叠加上一轮噪声预计算，也未减少粒子数量或渲染分辨率。释放阈值、原图消散 shader、静态属性的 hash、寿命与源颜色保持原算法。圆点覆盖、运动节奏和流场形态会变化，所以不要求逐像素相同。

应用内组合使用全部七项；桌面没有额外动态域扭曲，因此其中“两次动态 noise / 无 sin 动态 hash”不参与桌面计算，其余五项仍生效。

代码调用：

```javascript
const fx = new ParticleRenderer({ ...model, shaderVariant: 'combined' });
```

运行时根据 `usesFlowUniforms` 标识上传公共参数，使组合与单项 uniform 实验使用相同逻辑。构建器将七项变换组合到同一份 shader 中，而不是串联七个渲染 pass。

## 比较方法

- 先同步播放，检查释放方向、疏密、漂移和圆点浓度；再暂停逐帧观察差异图。
- “仅原始内容消散”应与原版一致，“仅粒子”显示组合对运动和圆点的影响。
- 点击 GPU 测量按钮，在同一 WebGL context 内交替执行原始/组合 shader，结束后恢复对照画面和控件。
- 所测 GPU 时间不含 CPU 公共参数求值、Canvas 2D、差异图和截图准备。计时不代表 CPU/GPU 总开销或最终帧率。
- 不把单项加速比例相加，也不以减少数学函数次数推断原生 GPU 指令数。

## 自动验收与基准

```text
node tools/build-shaders.cjs
node tests/clock.test.cjs
node tools/run-browser-tests.cjs --combined --benchmark
```

需要本机 Chrome 和 Playwright。验收覆盖单项与组合版本、桌面/应用、内/外屏、双方向、复现性、动态演化、原图 pass 和完整端点。

组合基准固定应用内屏、采样间距 1.5、fieldTime=1，分别测粒子 pass 和内部组合 pass：time=.4/.73/1.2 的负方向，以及 time=.73 的正方向；另有原算法自对照。保留全部样本和波动标识。

独立输出 `tests/combined-report.json`、`tests/combined-preview.png`，不覆盖之前的单项实验基准。详细计时方法及限制沿用 `07_近似算法单项对比.md`。

## 本轮结果

Chrome 155 / ANGLE D3D11 / RTX 3070：时钟测试通过，371 项算法/页面检查通过，包含七个原有单项和组合版本。另完成 10 组离线 GPU 对比与一次页面按钮计时。原有七个单项生成的顶点/片元源码 SHA256 均与组合加入前一致。

视觉统计使用采样间距 4、time=.73、fieldTime=1：应用内屏负方向的过渡层平均 RGBA 通道差约 21.71/255，alpha 总量为原版的 95.25%；正方向约 95.46%。这是原图和粒子叠加后的内部过渡层，不是仅粒子的覆盖率。变化集中在流场形状与圆点透明分布，完整端点与原图消散检查通过。

应用内屏、采样间距 1.5 的内部原图＋粒子 GPU 中位数如下：

| time | direction | 原版 ms | 组合 ms | 耗时变化 |
| ---: | ---: | ---: | ---: | ---: |
| .4 | -1 | .446 | .443 | -0.6% |
| .73 | -1 | .450 | .454 | +0.9% |
| 1.2 | -1 | .387 | .384 | -0.9% |
| .73 | +1 | .447 | .446 | -0.3% |

以上各组均触发波动标识。原算法自对照也出现较大变化，因此这些小差异不能归因于算法优化。页面按钮的单次测量显示约 -9.9%，同样标记波动较大，不能认定稳定收益。当前不宣称组合比原算法更快，保留原版作为正式演示默认路径。
