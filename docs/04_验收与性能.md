# 04 · 验收与性能

## 1. 已有证据与边界

本包可重跑 `node tests/clock.test.cjs` 和浏览器 `/tests/browser.html`。实际运行结果保存 `tests/browser-report.json`，场景阶段图位于 examples。GLSL 编译、逻辑与图像测试通过不等于手机端帧率达标。

此前在设计电脑 Chrome 中，当前素材轮廓识别的中位耗时约内屏 23 ms / 外屏 24 ms；包含高分辨率透明切片准备约 98 ms / 50 ms；首次约 168 ms / 60 ms。该组是旧原型测量：固定截图、CPU / Canvas 路径，不含截图采集与 GPU 上传，不能当成手机“100 ms 内”的承诺。本包附上原始测量 JSON（如版本来源中存在）。本包独立实现另测数据见 browser-report，二者不直接当成同一性能测试。

原型默认两屏应用内容约 35 万 / 21 万细粒子，粒子数取决于掩码、分辨率、采样阈值与步长。它是桌面显卡视觉基准，**不是手机上线预算**。

## 2. 真机预算建议（需实测校准）

| 档位 | 同时可见粒子总数起点 | 分析尺寸起点 | 使用方式 |
| --- | --- | --- | --- |
| 视觉基准 | 不限到手机预算；本包 1.5 步长 | 短边 320 | 对齐形态、尺寸和方向，不能直接上线 |
| 常规试验 | 3–9 万 | 短边 240–320 | 两屏合计，优先真正可见 Surface |
| 低档试验 | 1.5–3.5 万 | 短边 160–240 | 降采样，保留少量大颗粒与释放前沿 |
| 高档试验 | 8–15 万 | 短边 320 | 仍须测功耗、带宽与持续发热 |

以上是开发起点而非认证上限。避免所有图块同间距硬采样后无限增加点。可按 alpha 面积分配配额、按块做分层抽样、屏外剔除；随机种子固定。减少数量时补偿覆盖感，但不要把所有点放大成大圆斑。

60 Hz 的显示帧周期约 16.67 ms，120 Hz 约 8.33 ms；这是整个系统帧的时间，不是本效果独占预算。给粒子 pass 多少 ms 由系统团队与真实场景共同分配。记录 P50 / P95 / P99、掉帧、GPU / CPU、峰值内存与 30 次连续折展后的热状态。

## 3. 视觉验收矩阵

每项至少测桌面内屏 / 外屏、应用内内屏 / 外屏，开与合两向，外屏方向开关两种配置。

| 编号 | 验收项 | 通过标准 |
| --- | --- | --- |
| V01 | 完整端点 | q=0 与输入完整图一致；q=1 只剩独立底层，无残尘 |
| V02 | 背景隔离 | 桌面壁纸没有粒子；应用底色全画面不透明，卡片离开不漏壁纸 |
| V03 | 大卡片完整 | 应用主视觉、横幅无二次切线；内容 owner 不重复 |
| V04 | 原位转化 | 未碎化的内容没有整体平移、旋转或透视缩放 |
| V05 | 水平方向 | 同一中间帧一侧界面保留更多；翻转开关只翻转外屏方向 |
| V06 | 局部前沿 | 单张大卡内部也有“完整 → 碎化 → 粒子”的连续区域 |
| V07 | 无整屏突变 | 逐帧前后内容覆盖量连续，不能在阈值突然全变 / 全消失 |
| V08 | 无过长空白 | 入屏粒子在折展早期可见，不等出屏全部结束才开始 |
| V09 | 扰动自然 | 场连续、形状随时间变化、有疏密，不固定为卡片形状或匀速直线 |
| V10 | 主动势正确 | 涡流不把显著部分粒子拉回上游，无随机抖动方向错乱 |
| V11 | 粒子覆盖 | 过渡时不明显变薄；最小颗粒保留，少量大粒子可辨 |
| V12 | 颜色与接缝 | 无发黑、黑边、异常白色闪光；圆角与遮挡边缘干净 |
| V13 | 快速反转 | 相同会话不换种子 / 快照，不从初始状态重新播放 |
| V14 | 新界面 | 每次内容版本匹配；不能重用上一应用的图或掩码 |
| V15 | 生命周期 | 后台、锁屏、灭屏、来电、中断、Surface 丢失后资源正确回收 |

方向量化示例：隔离未粒化的原内容，在 tau≈0.73 时测左右三分之一区域保留 alpha。现有确认版本默认负方向左侧明显大于右侧，正方向相反。实际数值因内容和噪声不同，不使用某一截图的比例作为通用硬阈值。

## 4. 输入测试集

- 两套样例深色应用截图、浅色列表页、搜索页与键盘打开页。
- 带透明导航栏、浮动播放器、圆形头像、边到边主视觉、密集文字页。
- 暗色、亮色、渐变、多色背景；视频 / 直播等受限或动态 Surface。
- 外屏与内屏布局不同、横竖屏改变、字号与无障碍大字体、内容滚动中折展。
- 快速折返、角度静止、90° 阈值抖动、较慢手动开合、系统动画被暂停。

识别错误允许有明确降级，但必须能解释、记录并复现；不能用视觉上明显错误的粗网格静默冒充精细识别。
