# 折叠机细粒子动效 · 开发交付包

版本：1.0 / 2026-10-17。以当前确认的双折工程细粒子效果为基准。

已修复 UI 消散阶段的规则编织纹，默认渲染与预计算路径均使用新的释放粒度 hash。[修复说明与验证](docs/10_消散编织纹修复.md)。打开 `/demo/compare.html` 可在 150° 附近查看修复前后效果。

本地优化实验：已保存优化前 Git 基线 `ef78baa`，新增粒子固定噪声预计算及原算法对照开关。原图释放扰动缓存单独作为实验选项，默认关闭。实现、一次性回读代价与测试方法见 [固定噪声预计算](docs/06_固定噪声预计算.md)。

新增 [近似算法单项对比](docs/07_近似算法单项对比.md)：打开 `/demo/compare.html` 可分别比较七种候选，并使用同一 GPU context 测量当前实验。候选不默认替换正式演示算法。

新增 [组合算法对比](docs/08_组合算法对比.md)：对比页可选择“组合优化实验（7 项）”，同时启用七项改动，观察累积视觉差异并测量实际 GPU 开销。

**设计评审先打开 `粒子动效_设计规格与实现方案_v1.0.pptx`（31 页，可编辑图文＋可播放视频）。技术接入再看 `交付说明.html` 和 src/。**

本包交付两条路径：

1. 桌面：壁纸独立，上层图标、标题、卡片、时钟、文件夹等可见内容碎成细粒子。
2. 应用内：一张截图先通过本地图像分析识别完整内容块，再在原位置沿水平方向逐像素碎化成细粒子。大卡片不二次切分，背景保持应用底色。

不包含“一个完整图标当作一个大粒子”、整块面飞行、三维自旋、融合逐级纹理碎片、光影或三折机方案。分块只确定内容掩码与采样归属，不允许块先位移再粒化。

## 运行

有 Node.js 时，无需安装 npm 依赖：

```text
node tools/serve.cjs
```

打开终端打印的本机地址。页面切换桌面 / 应用内、拖动开合角度、勾选外屏方向、查看内容识别；演示按“闭合 → 展开 → 闭合”运行。

纯文档与参考视频可直接打开。WebGL 演示请走本机 HTTP 服务，不建议双击 file:// 运行。服务只绑定 127.0.0.1，不上传素材。

```text
node tests/clock.test.cjs
```

浏览器打开 `/tests/browser.html` 可重跑图像识别、掩码重组、GPU 渲染、方向前沿、端点与背景检查。

## 交付状态

提供的是经过浏览器验证的算法基准与原生接入设计，**不是手机原生 SDK、可安装 App 或性能认证**。目标系统 / 芯片 / GPU API / 可用截图权限尚未给定；由开发团队按实际系统能力实现截图获取、双屏生命周期、VSync、GPU 资源和帧同步。

原型 1.5 逻辑像素采样非常密，禁止把该粒子数直接作为所有手机的上线默认。先移植规则，再在目标真机调预算。任何性能降级都不能退回整屏突变、卡片整体漂移或应用壁纸漏底。
